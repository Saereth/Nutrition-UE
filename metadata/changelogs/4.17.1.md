# 4.17.1

Hotfix for 4.17.0.

## Fixed
- Reverted the `ca.wescook.nutrition` → `com.breakinblocks.nutrition` package rename from 4.17.0. Dependents like Magiculture Integrations and JustEnoughMagiculture reference Nutrition classes by fully-qualified name (`ca.wescook.nutrition.nutrients.NutrientList`, etc.); the rename caused `NoClassDefFoundError` at mod post-init in any pack that ships those dependents. Runtime package is now back to `ca.wescook.nutrition` for drop-in compatibility.

The `INutrientManager.add(List<Nutrient>, float)` API restoration from 4.17.0 is retained — that's the actual FTB Interactions Remastered crash fix ([FTB-Modpack-Issues #11896](https://github.com/FTBTeam/FTB-Modpack-Issues/issues/11896)) and works independently of the package path.
